# Доступ из интернета

Веб-интерфейс можно открыть не только в Tailscale, но и всем в интернете, например чтобы зайти с телефона без Tailscale. Каталог и программа при этом остаются закрытыми: без токена API отвечает `401`, открыты только сама страница, `/api/v1/health/live` и `/api/v1/data-version` (номер версии данных, без самих данных). Токен вводится один раз в **Настройках** веб-интерфейса.

## Как защищено

| Что | Как |
|---|---|
| Шифрование | Только HTTPS с настоящим сертификатом: токен не идёт по сети открытым текстом |
| Адрес сервера | Не виден: снаружи отвечает адрес вида `https://<узел>.<tailnet>.ts.net`, публичный IP сервера не открывается, порты на нём не открываются |
| Подбор токена | После `MIH_AUTH_FAILS` (10) неверных токенов за 15 минут адрес получает `429` на 15 минут. Токен 48 символов, перебрать его невозможно и без этого |
| Нагрузка | Не больше `MIH_RATE_LIMIT` (600) запросов в минуту с одного адреса, дальше `429` до конца минуты |
| Заголовки | `X-Frame-Options: DENY`, `X-Content-Type-Options: nosniff`, `Referrer-Policy: no-referrer` (ссылка `/play/…` с ключом не уходит на чужие сайты), `Strict-Transport-Security` для запросов по HTTPS |
| MCP | Порт MCP для агента остаётся только на `127.0.0.1` и в интернет не выходит |
| Настройки | Публичный адрес и токены только в `.env` на сервере; `.env` в git не попадает (`deploy/vps-test/.gitignore`) |

Реальный адрес клиента сервер берёт из `X-Forwarded-For`, но только если запрос пришёл от прокси из `MIH_TRUSTED_PROXIES` (по умолчанию loopback, Docker, Tailscale и локальные сети). Это безопасно, пока порт контейнера не опубликован на публичном адресе: compose-файл стенда публикует его только на loopback или адресе Tailscale.

## Включить (Tailscale Funnel)

Funnel проводит запросы из интернета через серверы Tailscale к узлу и выдаёт сертификат сам. Ничего нового на сервер не ставится, брандмауэр не меняется. Меняется одна запись Funnel этого узла, поэтому включает владелец сервера.

1. **Разрешить Funnel в tailnet** (один раз). В браузере откройте https://login.tailscale.com/admin/acls → вкладка **Access controls** (Правила доступа). Если в файле нет блока `nodeAttrs` с `"funnel"`, добавьте:

   ```json
   "nodeAttrs": [
     { "target": ["autogroup:member"], "attr": ["funnel"] }
   ]
   ```

   → **Save** (Сохранить). Ещё нужны **HTTPS Certificates** (HTTPS-сертификаты): **DNS** (DNS) → **Enable HTTPS** (Включить HTTPS), если ещё не включено. Если пропустить этот шаг, `tailscale funnel` сам напечатает ссылку, по которой это включается.

2. **Права на команду** (один раз, если `tailscale funnel` пишет `access denied`):

   ```bash
   sudo tailscale set --operator=$USER
   ```

3. **Открыть:**

   ```bash
   cd ~/mirtvonline-test/deploy/vps-test
   ./mihctl.sh public on
   ```

   Скрипт проверит, что стенд отвечает на `127.0.0.1:$MIH_PROXY_PORT` и что порт `MIH_FUNNEL_PORT` (443) на узле не занят ничем другим. Если занят, ничего не меняет и просит выбрать `MIH_FUNNEL_PORT=8443` или `10000`.

4. **Записать адрес** из вывода в `.env`: `MIH_PUBLIC_URL=https://…` и выполнить `./mihctl.sh deploy`. Тогда ссылки в пушах ведут на этот адрес.

Проверка: `./mihctl.sh public status`. Закрыть: `./mihctl.sh public off`, очистить `MIH_PUBLIC_URL`, `./mihctl.sh deploy`.

## Другие способы

- **Cloudflare Tunnel** со своим доменом: тоже без открытых портов, плюс можно поставить **Cloudflare Access** (вход по коду на почту) перед всем сайтом, тогда чужие не видят даже страницу. Нужен домен в Cloudflare. Туннель направляется на `http://127.0.0.1:$MIH_PROXY_PORT`.
- **Caddy или nginx** на сервере со своим доменом: нужен открытый порт 443 на публичном адресе, и сервер становится виден в интернете. Прокси направляется на `127.0.0.1:$MIH_PROXY_PORT`.

В обоих случаях лимиты и заголовки работают так же, `MIH_TRUSTED_PROXIES=private` подходит.

## Если что-то не так

- Все запросы получают `429`: прокси не передаёт `X-Forwarded-For`, и все клиенты выглядят как один адрес. Поднимите `MIH_RATE_LIMIT` или проверьте прокси.
- Свой токен введён с ошибкой много раз: подождите 15 минут или перезапустите контейнер (`./mihctl.sh deploy`).
