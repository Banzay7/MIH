# Валидные списки каналов

Код: `src/mih/lists.py`, команда `mih list`.

## Когда канал валиден

Канал попадает в список, если у него есть хотя бы один поток, который недавно реально запускался. Уровень потока:

| Уровень | Когда |
|---|---|
| `ok` | проверка сервера или запуск на устройстве прошли за последние 48 часов, и после этого сбоев не было |
| `doubtful` | работал за последние 7 дней, но сейчас сбоит, или последний успех старше 48 часов, или устройство после успеха не смогло его запустить |
| `unknown` | ещё ни разу не проверялся |
| `dead` | ни разу не заработал, не работает дольше 7 дней, в карантине, пропал из плейлиста, нужен DRM или логин |

Уровень фида равен уровню его лучшего потока, уровень канала равен уровню лучшего фида. По умолчанию в список идут только `ok`; `--level doubtful` добавляет сомнительные, `--level unknown` ещё и непроверенные.

На каждый фид в плейлисте одна запись с лучшим потоком. Копии со сдвигом времени (`+2`, `+4`) по умолчанию не включаются (`--timeshift`), каналы 18+ тоже (`--adult`).

## Геоблок

Сервер вне страны канала часто получает HTTP 403 или не получает ответа. Это считается обычным сбоем: зритель тоже обычно вне этой страны, и поток, который не открывается на сервере, скорее всего не заиграет и дома. Если устройство сообщило об успешном запуске (`POST /api/v1/streams/{id}/playback`), поток становится `ok` независимо от проверки сервера.

## Фильтры

| Параметр | Что делает |
|---|---|
| `--country RU` | страна канала: из `tvg-country` и из суффикса id iptv-org (`Perviykanal.ru` → RU); можно повторять |
| `--lang ru` | язык из `tvg-language`; названия (`Russian`, `русский`) приводятся к кодам |
| `--category news` | категория из `mih export` (news, sport, kids, movies...); можно повторять |
| `--epg-only` | только каналы с программой передач |
| `--epg-url URL` | адрес программы для заголовка плейлиста (`url-tvg`) |

## Что получается

- `<имя>.m3u`: плейлист для плеера, содержит ссылки на потоки;
- `<имя>.json`: каналы списка с уровнем и датой последнего успеха, а также `excluded`: каналы, подходящие под фильтр, но не попавшие в список, с причиной;
- `<имя>.csv`: каналы списка для таблицы.

Причины в отчёте: `geo_suspect` (последняя ошибка 403 или 451, вероятно блокировка по стране), `no_answer` (таймаут, нет соединения), `gone` (404, 410, домен не существует), `unchecked`, `never_worked`, `failing`, `stale`, `device_failed`, `drm`, `login`, `absent`, `no_stream`.

## Готовые списки и ссылка для плеера

Набор списков задаётся JSON-файлом в `MIH_LISTS_FILE`:

```json
{
  "ru": {"country": ["RU"]},
  "ru-news": {"country": ["RU"], "category": ["news"], "epg_url": "https://example.org/epg.xml.gz"},
  "kids": {"lang": ["ru"], "category": ["kids"], "level": "doubtful"}
}
```

Ключи: `country`, `lang`, `category`, `exclude_category`, `level`, `timeshift`, `adult`, `epg_only`, `epg_url`, те же, что у `mih list`. Без файла собирается один список `valid`: все каналы, которые играют.

Списки пересобираются после каждой проверки потоков (задача `health` планировщика) в `<MIH_EXPORT_DIR>/lists/`. Вручную: `mih list --presets`.

Ссылка для плеера: `http://<сервер>/lists/<имя>.m3u?token=<MIH_API_TOKEN>` (токен в адресе, потому что плееры не умеют передавать заголовки). Там же `<имя>.json` и `<имя>.csv`. Перечень списков с числом каналов и причинами исключения: `GET /api/v1/lists`.

## Весь каталог одним файлом

Вместе со списками в ту же папку пишутся `catalog.jsonl` и `catalog.csv`. Это всё сразу: каждый канал каталога и каждый его поток, без фильтров (каналы 18+ и копии со сдвигом тоже, со своими полями). В них есть ссылки на потоки, поэтому права у файлов 0640 и в выгрузку на Google Drive они не идут.

`catalog.jsonl`: один канал на строку, потоки внутри, лучший первым.

| Поле | Что это |
|---|---|
| `channel_id`, `name`, `aliases[]`, `tvg_ids[]` | канал и его другие названия |
| `search_keys[]` | ключи для поиска голосом: без регистра, дефисов и пробелов, латиницей, без слова «канал», народные имена (`россия24`, `rossiya24`, `russia24`, `ртр`, `первый`). Искать по `compact(запрос)` из `mih.identity.search_keys`: нижний регистр, ё→е, только буквы и цифры |
| `country`, `countries[]`, `languages[]`, `categories[]`, `logo_url` | метаданные |
| `level`, `reason`, `last_error`, `last_ok_at` | уровень канала (по лучшему потоку) и почему он ниже `ok` |
| `lists[]` | в какие готовые списки канал попал |
| `epg_available`, `now{title,start,stop}`, `next{title,start}` | программа на момент сборки файла (он пересобирается после каждой задачи) |
| `streams[]` | потоки: `stream_id`, `feed_id`, `region`, `timeshift_min`, `quality`, `format`, `source`, `level`, `reason`, `last_error`, `last_ok_at`, `home_ok_at`, `url`, `headers{user_agent, referer}`, `requires_headers` |

`requires_headers: true` значит, что поток открывается только с этими заголовками: плеер, который не умеет их передать, получит HTTP 403.

`catalog.csv`: то же для чтения глазами, одна строка на поток (канал без потоков одной строкой).

Ссылка: `http://<сервер>/lists/catalog.jsonl?token=<MIH_API_TOKEN>`. Имя `catalog` занято, готовый список так назвать нельзя.

## Отчёт о запуске дома

Проверка с сервера вне страны канала часто получает 403 или таймаут. Поэтому решающий голос у телевизора: после включения отправьте `POST /api/v1/streams/{stream_id}/playback` с `{"result": "started"}` или `{"result": "failed"}`. Успешный запуск сразу делает поток `ok` (даже из карантина) и в течение `MIH_HEALTH_DEVICE_TRUST_HOURS` (72 часа) неудачи проверки сервера по нему не засчитываются. Время последнего успешного запуска видно в `home_ok_at`.
