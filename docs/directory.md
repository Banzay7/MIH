# Справочник каналов

Код: `src/mih/directory.py`, команда `mih import-directory`.

Справочник отвечает на вопрос «какие каналы вообще есть», независимо от того, есть ли у нас для них поток. Источник: база iptv-org (CC0), файлы `channels`, `feeds`, `logos`, `blocklist`. По умолчанию берутся CSV из репозитория базы; `--base-url https://iptv-org.github.io/api/` берёт JSON из их API; `--from ПАПКА` читает локальные файлы `.csv` или `.json`.

Справочник меняется редко, запускать раз в несколько недель вручную достаточно.

## Что он даёт

- **Привязка.** Канал каталога связывается с записью справочника по `tvg-id` (`ChannelOne.ru@SD` → `ChannelOne.ru`), а если его нет, по названию или альтернативному названию, которое в совместимой стране есть только у одной записи («Первый канал» → `ChannelOne.ru`). Неоднозначное название (Channel One есть в RU, US, LK) не привязывается.
- **Склейка дублей.** Каналы с одним `tvg-id` или одной записью справочника объединяются в самый старый: фиды, потоки, псевдонимы, избранное и привязки программы переносятся. Склейка идёт и после каждого импорта плейлиста.
- **Страна, языки, категории.** Категории справочника идут первыми (`category_source: directory`), языки берутся из фидов и приводятся к кодам ISO 639-1. Поэтому фильтры `mih list --lang ru --category news` работают и для плейлистов без `tvg-language`.
- **Каналы без потока.** `--country RU` (можно повторять) добавляет в каталог каналы страны, которых в нём ещё нет. У них нет фидов, состояние `none`; если позже плейлист принесёт такой канал, поток попадёт на него же. Закрытые каналы и каналы из blocklist iptv-org не добавляются, NSFW получают категорию `adult`.

## Названия

Метки плейлистов в названии не считаются частью имени: `(576i)`, `(406p)` и любое другое разрешение, `[Geo-blocked]`, `[Not 24/7]`, кружки Free-TV (`Ⓖ`, `Ⓢ`, `Ⓨ`).

## Каналы из программы передач

Программа передач перечисляет гораздо больше каналов, чем плейлисты (только iptvx.one около 4000). Каждый канал программы, которого нет в каталоге под тем же названием, при импорте программы становится каналом каталога без фида. Так каталог показывает его, а плейлист, который позже принесёт поток, попадёт на этот же канал. Фида нет, поэтому программа к нему не привязывается и не хранится, пока не появится поток (`MIH_EPG_SCOPE` по-прежнему решает, что хранить). `mih import-directory` делает то же для уже загруженных программ, затем привязывает такие каналы к справочнику и склеивает дубли.
