# Выгрузка каналов на Google Диск

Сервис сам кладёт в одну папку Google Диска два файла и держит их свежими:

- `channels.json`: все каналы с категориями, языками, странами, здоровьем потоков и наличием программы;
- `channels.csv`: то же, строка на канал, открывается в Google Таблицах (двойной щелчок по файлу на Диске, затем **Открыть в приложении «Google Таблицы»**).

Ссылок на потоки в них нет. Плейлисты (`*.m3u`) и `catalog.*` содержат ссылки и токены провайдеров и на Диск не попадают никогда: список файлов для выгрузки зашит в код (`mih/drive.py`, `UPLOAD`), а перед каждой выгрузкой оба файла проверяются на ссылки потоков и на `MIH_API_TOKEN`. Нашлась хоть одна, выгрузка отменяется с ошибкой.

## Когда

Задача `drive` встроенного планировщика, раз в `MIH_EVERY_DRIVE` (по умолчанию `6h`). Если каналы с прошлой выгрузки не изменились, файлы не трогаются. Файлы обновляются на месте, поэтому ссылка на них и открытая таблица остаются прежними. Запуск вручную: `mih run-job drive` или кнопка задачи на экране «Статус». Ошибка выгрузки приходит пушем, успешная видна в ленте и в сводке.

## Настройка (один раз)

Нужен токен Google Диска. Его получают на своём компьютере, где есть браузер, программой [rclone](https://rclone.org/downloads/):

1. Установите rclone. Windows: `winget install Rclone.Rclone`; macOS: `brew install rclone`.
2. Выполните `rclone authorize "drive"`. Откроется браузер.
3. Выберите свой аккаунт Google, нажмите **Allow** (Разрешить).
4. В терминале появится строка вида `{"access_token":"...","refresh_token":"...",...}`. Это токен, целиком одной строкой.

Затем в `.env` сервиса:

```
MIH_DRIVE_TOKEN={"access_token":"...","refresh_token":"...","expiry":"..."}
MIH_DRIVE_FOLDER_ID=<ID папки>
```

ID папки: откройте папку на Диске в браузере, это часть адреса после `/folders/`. Перезапустите сервис (на тестовом стенде `./mihctl.sh deploy`) и проверьте: `mih run-job drive`.

Токен даёт доступ ко всему Диску этого аккаунта, поэтому хранится только в `.env` (права `600`) и в `<data>/drive/rclone.conf` (права `600`), в логи и события не пишется. Отозвать: **Аккаунт Google** → **Безопасность** → **Сторонние приложения с доступом к аккаунту** → **rclone** → **Удалить доступ**.

## Что лежит на сервере

`<data>/drive/out/`: последние выгруженные файлы; `<data>/drive/state.json`: когда и что выгружено; `<data>/drive/rclone.conf`: настройки rclone с обновляемым токеном. Новый токен в `MIH_DRIVE_TOKEN` (другой `refresh_token`) заменяет старый при следующем запуске.
